# filipino-wordnet

## Contents
* The API folder contains the Jupyter notebooks used to run the FilWordNet server API.
* The code folder contains the Jupyter notebooks for running the pipeline to generate the resources (COHFIE, the network, and the semsets). The notebooks are separated per module in the pipeline, which are represented by subfolders.

---

## Installation
### I. FilWordNet Pipeline (NetSci)

**Requirements**:
* Anaconda

**Package Dependencies** (can be installed using `pip install`):
* Scrapy
* Selenium
* BeautifulSoup4
* CDLib
* iGraph
* LeidenAlg
* CDLib

### II. API
Refer to the api folder to access the FilWordNet Server API to start the server.
